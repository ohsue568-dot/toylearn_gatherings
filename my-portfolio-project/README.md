# 내 포트폴리오 프로젝트

이 프로젝트는 '나'라는 브랜드를 캠페인처럼 풀어내는 독특한 컨셉의 포트폴리오 웹사이트입니다.

## 🎨 Concept
저를 하나의 브랜드로 설정하여, 방문자가 브랜드 캠페인을 경험하는 듯한 느낌을 받을 수 있도록 스토리텔링 기반으로 구성했습니다. 미니멀한 디자인과 명확한 브랜드 보이스를 통해 메시지를 전달합니다.

## 📁 Structure
- **docs**: 프로젝트의 기획 의도, 컨셉, 프롬프트, 참고 자료를 정리한 문서 폴더입니다.
- **src**: 실제 웹사이트를 구성하는 HTML, CSS, JavaScript 소스 코드 폴더입니다.
- **design**: 와이어프레임, 스타일 가이드 등 디자인 관련 산출물 폴더입니다.

## 🛠 Tech Stack
- HTML5, CSS3, JavaScript
- GSAP (for animations)
- Figma (for design)
- GitHub Pages (for deployment)

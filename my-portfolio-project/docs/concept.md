# 포트폴리오 웹사이트 컨셉

## 🎨 프로젝트 주제
콘텐츠 마케터 취업을 위한 개인 브랜딩 포트폴리오 웹사이트

## ✨ 전체 컨셉(Concept)
'나'를 하나의 브랜드로 설정하여, 브랜드 캠페인 기획서를 웹사이트 형태로 표현하는 스토리 기반의 포트폴리오입니다. 저만의 세계관, 톤앤매너, 콘텐츠 전략을 통해 전문성을 어필합니다.

## 🧩 메뉴 구성
- **Home**: '나라는 브랜드'의 핵심 메시지를 전달하는 첫인상 페이지.
- **About**: 저의 가치관과 전문성을 소개하는 브랜드 아이덴티티 섹션.
- **Projects**: 진행했던 캠페인, 광고, 콘텐츠 기획 포트폴리오를 아카이빙.
  - 각 프로젝트는 문제 정의, 해결 전략, 결과(KPI)를 중심으로 한 케이스 스터디 형식으로 구성.
  - 기획서 원본(PDF) 또는 결과물(영상)을 임베드하여 구체적인 내용을 확인할 수 있도록 함.
- **Skills**: 마케팅 툴 활용 능력, 데이터 분석 및 시각화 역량을 소개.
- **Blog**: 마케팅 관련 인사이트나 생각을 정리한 아티클 (선택 사항).
- **Contact**: 이메일, SNS 등 연락 가능한 채널을 안내.

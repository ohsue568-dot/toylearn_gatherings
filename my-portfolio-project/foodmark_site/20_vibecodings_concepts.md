당신은 웹 디자이너(UI/UX), 웹 퍼블리셔(UI 개발자), 프론트엔드 개발자, 백엔드 개발자, 풀스택 개발자로 각 30년 이상 경력이 있는 전문가 집단입니다. 다음 지침에 따라 웹페이지 UI 및 디자인을 리뉴얼 업데이트 해주세요.

[목표]
- 기존 혼밥 레시피 웹페이지를 참고하여 리뉴얼
- 멀티 페이지 구조: index.html, recipes.html, ingredients.html, notice.html
- 모든 메뉴 클릭 시 각 페이지로 이동 가능하며 404 오류 없음

[가이드라인]
1. 색상 컨셉:
   - 메인 배경: 크림 베이지 (#FFF7E9)
   - 보조/포인트: 웜 오렌지 (#FFA756)
   - 강조 CTA 버튼: 코랄 레드 (#FF6B6B)
   - 텍스트/기본 UI: 다크 브라운 (#4E342E)

2. UI/UX 개선:
   - 히어로 섹션, 인기 레시피, 버튼 디자인 등 기존 HTML 구조 유지
   - 인기 레시피 카드 또는 “오늘의 추천 레시피 보기” 버튼 클릭 시 각각의 상세 페이지 이동
   - 메뉴 또는 레시피 카드 배치, 이미지, 카드 크기, 그림자, hover 효과 등 시각적 개선
   - 모바일 반응형 그리드 유지

3. 이미지:
   - 레시피 카드 및 히어로 섹션 이미지는 실제 음식 이미지나 어울리는 이미지가 들어가도록 URL 또는 이미지 태그 포함

4. 페이지별 최소 내용:
   - index.html: 히어로 섹션 + 인기 레시피 카드 + CTA 버튼
   - recipes.html: 레시피 목록 카드, 각 카드 클릭 시 recipe-detail.html(또는 index.html로 임시 연결 가능)
   - ingredients.html: 식재료 목록, 카드 또는 리스트
   - notice.html: 공지사항/이벤트 리스트

5. 디자인 세부:
   - 버튼, 카드, 링크 색상과 hover 효과 등 컬러 가이드 적용
   - 폰트, 여백, 라운딩, 그림자 등 UI 요소 현대적으로 개선
   - 레시피 카드 및 이미지 섹션 시각적 강조

6. 출력물:
   - index.html, recipes.html, ingredients.html, notice.html 전체 코드 제공
   - 각 파일 링크가 정확히 연결되어 멀티 페이지 구조 정상 작동
   - 폴더 구조까지 함께 제시

7. 추가 옵션:
   - Bootstrap 5 활용 가능
   - 추가적인 시각적 개선(그라데이션, hover 애니메이션, 라운드 카드 등) 포함

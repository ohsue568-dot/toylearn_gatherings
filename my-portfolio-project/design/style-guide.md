# 스타일 가이드

이 문서는 프로젝트의 일관된 디자인을 유지하기 위한 규칙을 정의합니다.

## 1. 색상 (Colors)
- **Primary Black**: `#121212` (주요 텍스트, 헤드라인)
- **Primary White**: `#FFFFFF` (배경)
- **Accent/Gray**: `#CCCCCC` (보조 텍스트, 구분선)

## 2. 타이포그래피 (Typography)
- **Font Family**: Pretendard
- **Heading 1 (h1)**: 3rem, Bold (700)
- **Heading 2 (h2)**: 2.5rem, Bold (700)
- **Body Text (p)**: 1.1rem, Regular (400)

## 3. 레이아웃 (Layout)
- **Grid**: 콘텐츠 정렬을 위해 그리드 시스템 사용을 권장합니다.
- **Spacing**: 요소 간의 여백은 8px의 배수를 사용합니다 (8, 16, 24, 32...).

## 4. 컴포넌트 (Components)
- **Buttons**: 명확한 Call-to-Action을 제공하며, 호버 상태에 대한 시각적 피드백이 있어야 합니다.
- **Navigation**: 상단에 고정되며, 현재 활성화된 섹션을 시각적으로 표시합니다.
